# Phase 5 development corpus

Public / project-approved reference materials used to demonstrate document-backed
domains locally and in staging.

- `policy/` — Boston planning analyses already present under `public/Policies/` plus short digests
- `zoning/` — ISD/zoning public-reference overview with official URL attribution
- `meetings/` — transcript-format neighborhood discussion excerpts (non-binding)
- `news/` — journalism-vs-official-data policy note
- `community/` — neighborhood-organization public overview

No private resident data. Official URLs are cited in-file where applicable.
